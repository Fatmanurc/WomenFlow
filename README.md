# WomenFlow
# AI-Powered Women's Health Mobile Application

WomenFlow is an AI-supported mobile application designed to provide women with personalized health tracking and educational support. The project focuses on menstrual cycle tracking, fertility and ovulation analysis, pregnancy risk estimation, menopause risk estimation, and AI-powered conversational support.

TÜBİTAK 2209-A Supported Undergraduate Research Project

# Features
- Menstrual cycle tracking and prediction
- Ovulation and fertility analysis
- Pregnancy risk estimation
- Menopause risk estimation
- Abnormal menstrual pattern detection
- Cycle-based health recommendations
- AI-powered chatbot
- User health data tracking
- Firebase-based authentication and data storage
